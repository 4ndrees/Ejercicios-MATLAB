# Ejercicios-MATLAB
Ejercicios y apuntes del curso gratuito Matlab Onramp. Repositorio de apuntes básicos para programación usando Matlab.

## Contenidos 

| Bloque | Temas |
| --- | --- |
| Fundamentos | Operadores, variables, archivos, indexación lógica y scripts |
| Arrays | Vectores, matrices, dimensiones, indexación y operaciones |
| Gráficas | `plot`, estilos, leyendas, superposición e histogramas |
| Tablas | CSV, `readtable`, indexación, filtrado y ordenación |
| Control de flujo | `if`/`elseif`/`else` y bucles `for` |

## Requisitos

- MATLAB con las funciones básicas de cálculo, gráficas y tablas. **No se requieren toolboxes adicionales** para los ejemplos incluidos.
- No se necesitan datasets ni archivos externos: el ejemplo de CSV crea un archivo temporal y lo elimina al terminar.

## Cómo usarlo

1. Descarga o clona el repositorio y abre la carpeta en MATLAB.
2. Abre un archivo de `src/`, por ejemplo [`arrays.m`](src/arrays.m).
3. Ejecuta todo el script con **Run** o una sección concreta, delimitada por `%%`, con **Run Section**.

## Alcance y estado

Material introductorio de MATLAB; no pretende ser un curso avanzado.
